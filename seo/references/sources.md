# Источники

Официальная документация поисковых систем:

- Яндекс Вебмастер, справка: https://yandex.ru/support/webmaster/
- Яндекс, рекомендации по созданию сайтов: https://yandex.ru/support/webmaster/yandex-indexing/webmaster-advice.html
- Яндекс Вордстат (частотность запросов): https://wordstat.yandex.ru/
- Google Search Central, руководство по SEO для начинающих: https://developers.google.com/search/docs/fundamentals/seo-starter-guide
- Google, ссылки на заголовки (title) в выдаче: https://developers.google.com/search/docs/appearance/title-link
- Google, сниппеты и meta description: https://developers.google.com/search/docs/appearance/snippet
- Google, спам-политики: https://developers.google.com/search/docs/essentials/spam-policies
- Schema.org (микроразметка): https://schema.org/
- PageSpeed Insights (скорость): https://pagespeed.web.dev/

Длина title и description в скилле указана как ориентир: поисковые системы не задают жёстких лимитов в символах, а обрезают сниппет по ширине.
