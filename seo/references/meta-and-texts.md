# Мета-теги и SEO-тексты: правила

## Title
- Главный запрос ближе к началу.
- Ориентир по длине до 60–70 символов. У Google нет жёсткого лимита, длинный title просто обрезается в выдаче по ширине.
- Уникальный для каждой страницы.
- Формула: `Главный запрос + уточнение или выгода | Бренд`.
- Без перечисления ключевых слов через запятую.

Пример для страницы услуги:
- Плохо: `Главная`
- Плохо: `Дизайн сайтов, создание сайтов, сайты на Тильде, веб-дизайн Москва`
- Хорошо: `Создание сайтов на Тильде в Москве под ключ | Студия N` (54 символа)

## Description
- Ориентир 120–160 символов.
- Отвечает на вопрос «почему кликнуть именно сюда»: польза, факты (сроки, цена от, гарантия), призыв к действию.
- Главный запрос встречается естественно.
- Поисковик может заменить description своим фрагментом текста, если сочтёт его точнее. Это нормально.

Пример:
`Сделаем сайт на Тильде за 14 дней: дизайн, тексты и SEO-настройка. Покажем макет до оплаты. Оставьте заявку и получите расчёт стоимости` (≈140 символов)

## H1
- Один на страницу.
- Содержит главный запрос, звучит как заголовок для человека.
- Может отличаться от title: title пишется для выдачи, H1 для страницы.

## Структура H2–H3
- Каждый H2 это смысловой блок страницы: «Что входит», «Сколько стоит», «Как мы работаем», «Частые вопросы».
- В H2–H3 уместно использовать дополнительные запросы и вопросы пользователей.

## SEO-текст
1. Сначала ответ на главный вопрос пользователя, потом детали.
2. Запросы в естественной форме и разных словоформах, без повторов в каждом предложении.
3. Короткие абзацы, списки, таблицы.
4. Блок «Частые вопросы» закрывает дополнительные запросы и подходит под разметку FAQPage.
5. Факты и конкретика вместо общих слов («опыт 5 лет, 120 проектов» вместо «большой опыт»).
6. Не копировать тексты с других сайтов: неуникальный контент ранжируется хуже.

## Alt у картинок
- Описывает, что изображено: `Главный экран сайта кофейни на Тильде, мобильная версия`.
- Запрос только если он подходит по смыслу.
- Декоративным картинкам alt можно оставить пустым: `alt=""`.

## Как выдавать результат
Всегда 2–3 варианта title и description, у каждого длина в символах:

```
Title
1. ... (58)
2. ... (63)

Description
1. ... (148)
2. ... (135)

H1: ...
Структура: H2 ... / H2 ... / H2 Частые вопросы
```
