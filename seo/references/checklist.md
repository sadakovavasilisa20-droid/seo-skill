# Чек-лист SEO-аудита страницы

Проходи по порядку. 🔴 критично, 🟠 важно, 🟡 желательно.

## 1. Индексация
- 🔴 Нет `<meta name="robots" content="noindex">`, если страница должна быть в поиске
- 🔴 Страница не закрыта в robots.txt (проверь `/robots.txt` сайта)
- 🟠 Есть `<link rel="canonical">`, он указывает на саму страницу или на правильный основной адрес
- 🟠 Код ответа 200, нет цепочек редиректов
- 🟡 Страница есть в sitemap.xml

## 2. Title
- 🔴 Title есть и не пустой
- 🟠 Главный запрос в title, ближе к началу
- 🟠 Длина: ориентир до 60–70 символов, длиннее обрежется в выдаче
- 🟠 Уникальный, не повторяется на других страницах
- 🟡 Есть бренд в конце

## 3. Meta description
- 🟠 Description есть
- 🟠 Длина: ориентир 120–160 символов
- 🟠 Описывает пользу страницы, есть призыв к действию
- 🟡 Главный запрос встречается естественно

## 4. Заголовки
- 🔴 Ровно один H1
- 🟠 H1 содержит главный запрос и соответствует содержанию
- 🟠 Иерархия без пропусков: H1 → H2 → H3
- 🟡 В H2–H3 есть дополнительные запросы

## 5. Контент
- 🟠 Текст отвечает на запрос пользователя, а не просто набит ключевыми словами
- 🟠 Объём не «тонкий»: для услуги или статьи обычно нужно больше пары абзацев (точный объём смотри у конкурентов в топе)
- 🟠 Нет переспама: запрос не повторяется неестественно часто
- 🟡 Есть списки, таблицы, ответы на частые вопросы

## 6. Картинки
- 🟡 У всех значимых картинок есть alt с описанием
- 🟡 Картинки сжаты, современные форматы (WebP, AVIF)
- 🟡 Понятные имена файлов

## 7. Мобильная версия и техника
- 🟠 Есть `<meta name="viewport">`
- 🟠 Указан язык: `<html lang="ru">`
- 🟠 Скорость загрузки: проверить в PageSpeed Insights (вручную)
- 🟡 Сайт работает по HTTPS

## 8. Ссылки
- 🟡 Есть внутренние ссылки на важные страницы сайта
- 🟡 Тексты ссылок понятные, не «тут» и «подробнее»
- 🟡 Нет битых ссылок

## 9. Сниппет и соцсети
- 🟡 Микроразметка Schema.org (JSON-LD) под тип страницы: Organization, Product, Article, FAQPage, LocalBusiness
- 🟡 Open Graph: og:title, og:description, og:image (для красивых превью в соцсетях и мессенджерах)
- 🟡 Favicon

## 10. Особенности Яндекса
- 🟠 Регион сайта указан в Яндекс Вебмастере (для локального бизнеса)
- 🟡 Организация добавлена в Яндекс Бизнес (для локального бизнеса)
- 🟡 Подключена Яндекс Метрика (нужна для анализа поведения)
