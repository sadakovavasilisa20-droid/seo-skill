# Путь развития скилла

## Версия 1: одна страница
Скилл проверял одну страницу по её HTML и писал мета-теги. Оценка преподавателя: 5/10 как учебная работа, 2/10 по сравнению с рабочим стеком.

Главное замечание: **масштаб.** Настоящий SEO-аудит смотрит на сайт целиком и идёт по жёсткому процессу, где отчёт нельзя собрать, пока не закрыт чек-лист.

## Версия 2: аудит сайта с гейтом (текущая)
Я пошла от процесса, а не от количества скриптов: сначала определила, какие вопросы заказчика должен закрыть аудит, потом под каждый вопрос сделала шаг со своим файлом результата.

| Вопрос заказчика | Шаг |
|---|---|
| Видит ли поиск мой сайт? | robots.txt и sitemap, ручная проверка индексации |
| Нет ли технических поломок? | обход сайта, битые ссылки, коды ответов, редиректы |
| Понятна ли поиску структура? | ссылочный граф: сироты, тупики, глубина, вес страниц |
| Правильно ли оформлены страницы? | on-page по всем страницам, дубли между страницами |
| Что ищут мои клиенты и есть ли у меня под это страницы? | спрос из Вордстата, кластеры, непокрытый спрос |
| Сколько трафика я могу получить? | модель трафика, 3 сценария с допущениями |
| Нет ли рисков штрафов? | проверка по 152-ФЗ, иностранные сервисы, Meta |
| С чего начать? | приоритизация и план работ по неделям |

Ключевые решения:
1. **Гейт.** Каждый шаг пишет отметку в `state.json`. `gate.py` проверяет все отметки и файлы. `build_report.py` сам вызывает гейт и без него не работает. Пропуск разрешён только для спроса и трафика, причина обязательна и попадает в отчёт.
2. **Ручные проверки как шаг.** То, что скрипт не видит (скорость, выдача, Метрика), закрывается заметкой. Если проверка нашла проблему, она становится задачей в плане.
3. **Никаких выдуманных цифр.** Частотность только из выгрузки, CTR помечен как гипотеза, в отчёте раздел «Ограничения».
4. **Только стандартный Python.** Скилл работает на любом компьютере без установки библиотек.

Проверка: полный прогон на реальном сайте (`examples/verashtogrina/report.md`). Гейт сначала не пустил отчёт без брифа, спроса и ручных проверок, после их закрытия собрал отчёт.

## Версия 3: что дальше
- Подключение к API Яндекс Вебмастера и Метрики: реальные позиции, CTR и индексация вместо ручных проверок
- PageSpeed Insights API с ключом: скорость всех ключевых страниц автоматически
- Анализ конкурентов из брифа: те же шаги для 3–5 сайтов из топа и сравнение
- Сборка презентации для заказчика из отчёта, тоже через гейт
- Проверка внешних ссылок по реестру РКН через официальный сервис
