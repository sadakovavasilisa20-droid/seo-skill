# SEO-скилл для Claude

Скилл учит Claude делать **SEO-аудит сайта целиком** по строгому процессу из 15 шагов и собирать отчёт и презентацию для заказчика. Ещё он умеет быстро проверять одну страницу и писать мета-теги и SEO-тексты под Яндекс и Google.

Учебный проект по предмету «Поисковая оптимизация и контекстная реклама».
Автор: Садакова Василиса.

## Как устроен полный аудит

```
1 Бриф → 2 Обход сайта → 3 robots.txt и sitemap → 4 Ссылочный граф → 5 Техника
→ 5б Скорость → 6 On-page → 7 Риски по законам РФ → 8 Спрос → 9 Модель трафика
→ 9а Конкуренты → 10 Ручные проверки → 11 ГЕЙТ → 12 Отчёт → 13 Дека для заказчика
```

| Шаг | Что делает |
|-----|------------|
| Бриф | бизнес, регион, цель сайта, главные запросы. Без брифа аудит не начинается |
| Обход сайта | проходит по всем страницам своего домена (с учётом robots.txt), потом догружает адреса из sitemap, на которые нет ссылок. Понимает кодировку windows-1251 и склеивает адреса с метками utm, yclid и другими |
| robots.txt и sitemap | сравнивает карту сайта с тем, что реально нашлось: мусор в sitemap, страницы вне sitemap |
| Ссылочный граф | битые ссылки, страницы-сироты (есть в sitemap, но без ссылок), тупики, глубина вложенности, внутренний вес страниц (PageRank) |
| Техника | зеркала (http/https, www, слэш на конце) и 301-редиректы, ложная 404, смешанный контент, битые внешние ссылки, тяжёлые картинки |
| Скорость | PageSpeed Insights API: мобильная и десктоп, LCP, CLS. Без ответа API шаг не засчитывается |
| On-page | ошибки на всех страницах сразу: дубли title, description и H1, пустые и длинные теги, тонкий текст |
| Риски по законам РФ | формы без согласия на обработку данных (152-ФЗ), нет политики, иностранные счётчики, ссылки на сервисы Meta без пометки |
| Спрос | группирует запросы из выгрузки Вордстата, привязывает к страницам, находит спрос без своей страницы |
| Модель трафика | три сценария роста трафика (осторожный, базовый, смелый) с явными допущениями |
| Конкуренты | сайты из брифа: сколько страниц, сколько текста, есть ли микроразметка. Разрывы попадают в план работ |
| Ручные проверки | 10 пунктов, которые скрипты не видят: скорость, мобильная версия, индексация, Метрика, выдача |
| **Гейт** | **не даёт собрать отчёт и деку, пока хоть один шаг не пройден.** Проверяет, что все шаги сделаны по одному обходу (`run_id`), что у ручных проверок есть доказательство и что конкуренты из брифа не пропущены. Пропустить можно только скорость, спрос, трафик и конкурентов, и только с причиной |
| Отчёт | главное, топ-10 задач, разделы по шагам, план работ по неделям и ограничения аудита |
| Дека | презентация 16:9 для заказчика из тех же данных, цвет бренда клиента, ограничения аудита на отдельном слайде |

## Как установить

**Claude Code:**

```bash
git clone https://github.com/sadakovavasilisa20-droid/seo-skill.git
cp -r seo-skill/seo ~/.claude/skills/
```

**Claude.ai:** заархивируйте папку `seo` в ZIP и загрузите в настройках, в разделе Skills.

## Как пользоваться

Напишите Claude:
- «Сделай SEO-аудит сайта https://example.com. Бизнес: студия маникюра, Москва, цель: записи»
- «Быстро проверь SEO этой страницы: https://example.com/uslugi»
- «Напиши title и description для страницы "дизайн сайтов на Тильде"»

Или вручную:

```bash
cd seo/scripts
python3 brief.py --out audit --site https://example.com --business "…" --region "…" --goal "…" --queries "…; …"
python3 run_all.py https://example.com --out audit --queries wordstat.csv
python3 checklist.py --out audit show          # закрыть ручные проверки
python3 gate.py --out audit                    # проверить, всё ли пройдено
python3 build_report.py --out audit            # отчёт: audit/report.md
python3 build_deck.py --out audit              # дека: audit/deck.html
```

Тесты: `python3 -m unittest discover -s tests -v`

## Принципы

- Отчёт только через гейт: никаких выводов по недопройденному аудиту
- Цифры только из данных: частотность из Вордстата, CTR помечен как гипотеза, все допущения в отчёте
- Риски по законам — это признаки для проверки, а не юридическое заключение
- Никаких «серых» методов: накрутки, скрытого текста, покупки ссылок
