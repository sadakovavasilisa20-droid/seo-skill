# SEO-скилл для Claude

Скилл учит Claude делать **SEO-аудит страницы** и писать **мета-теги и SEO-тексты** под Яндекс и Google.

Учебный проект по предмету «Поисковая оптимизация и контекстная реклама».
Автор: Садакова Василиса.

## Что умеет

**1. SEO-аудит страницы**
Даёте ссылку или HTML, скилл проверяет индексацию, title, description, заголовки, текст, картинки, мобильную версию, ссылки, микроразметку и Open Graph. На выходе таблица проблем с приоритетами (🔴 критично, 🟠 важно, 🟡 желательно), готовые правки и список того, что проверить вручную.

**2. Мета-теги и SEO-тексты**
По главному запросу пишет 2–3 варианта title и description с длиной в символах, H1, структуру H2–H3, SEO-текст и alt для картинок.

## Структура

```
seo/
├── SKILL.md                    инструкции для Claude
├── references/
│   ├── checklist.md            чек-лист аудита из 10 разделов
│   ├── meta-and-texts.md       правила для title, description, H1, текстов, alt
│   └── sources.md              официальные источники Яндекса и Google
└── scripts/
    └── seo_check.py            сбор SEO-данных страницы в JSON
examples/
└── audit-tilda.md              пример аудита реальной страницы
```

## Как установить

**Claude Code:** скопируйте папку `seo` в `~/.claude/skills/`

```bash
git clone https://github.com/sadakovavasilisa20-droid/seo-skill.git
cp -r seo-skill/seo ~/.claude/skills/
```

**Claude.ai:** заархивируйте папку `seo` в ZIP и загрузите её в настройках, в разделе Skills.

## Как пользоваться

Просто напишите Claude:
- «Сделай SEO-аудит https://example.com, главный запрос: доставка цветов Москва»
- «Напиши title и description для страницы услуги "дизайн сайтов на Тильде"»
- «Почему эта страница плохо ранжируется?» и приложите HTML

Скрипт можно запускать и отдельно, нужен только Python 3:

```bash
python3 seo/scripts/seo_check.py https://example.com
```

## Принципы

- Рекомендации по официальной документации Яндекса и Google (`seo/references/sources.md`)
- Никаких «серых» методов: накрутки, скрытого текста, покупки ссылок
- Никаких выдуманных цифр: частотность и трафик скилл предлагает проверить в Вордстате и вебмастерах
